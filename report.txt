1. COMPLETED SOURCE CODE ARCHITECTURE
--------------------------------------------------------------------------------

We created/updated the following modular files in your workspace:

- /sqlite_helper.py : High-performance native Python script utilizing Python's
  built-in sqlite3 database drivers. Validates, queries, and maps books, chapters, 
  and verses from any uploaded Bible SQLite .db, .sqlite, or .sqlite3 file. 
  Accurately detects language encoding (Tamil vs English) automatically.
  
- /tts_helper.ts : Pure Node.js WebSockets client making direct, secured, real-time 
  calls to Microsoft Edge Neural TTS servers. Eliminates raw Python pip dependencies,
  ensuring 100% cloud platform reliability.

- /server.ts : Multi-route Express application integrating Vite middleware, 
  Multer disk storage uploads, project serialization configs, in-memory render task
  queues, ffprobe audio duration mapping, and actual FFmpeg video overlay compilers.

- /src/types.ts : Strong static TypeScript interfaces defining structured configurations 
  for database metadata, verses, uploaded custom fonts, text styles, frames, 
  templates, and rendering queue states.

- /src/templatesData.ts : Procedural generator engine creating over 1000 genuinely 
  different template presets dynamically. Combines distinct categories of background 
  gradients, text styles, frames, custom particles, and entry/exit animation timings.

- /src/App.tsx : Desktop-inspired visual workspace. Supports book/chapter selectors,
  scrolling checkboxes for batch exports, interactive safe-area previews, 
  watermark opacity adjustments, intro/outro uploads, and real-time progress monitors.

--------------------------------------------------------------------------------
2. COMPLETED USER WORKFLOW PIPELINE
--------------------------------------------------------------------------------

1. Setup: User uploads their own Bible database (.db) and custom fonts pack (.ttf).
2. Detection: System reads schema, counts verses, and detects Tamil/English.
3. Selection: Choose target Book, Chapter, and specific Verses.
4. Auto-Design: Unique combination of background, text glow, frame, particles, and 
   neural voice is automatically assigned to every selected verse.
5. Synthesis: Runs Edge TTS on the server to generate actual, professional audio.
6. Sync: Measures exact audio length via ffprobe, locking animations to audio time.
7. Composing: Combines transparent slide graphics (drawn at actual target resolution 
   by browser Canvas) with dynamic background layers.
8. Rendering: Compiles slides, audio, optional watermarks, and optional intros/outros
   directly into native H.264 MP4 videos using server-side FFmpeg.
9. Batch Export: Generates and downloads separate videos for every selected verse!
